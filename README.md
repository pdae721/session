# Session · 바탕화면 매트릭스

Windows 10/11 x64 바탕화면에서 할 일과 Claude·Codex 사용 한도를 확인하는 위젯입니다.

## 설치

1. [GitHub Releases](https://github.com/pdae721/session/releases/latest)에서 `Session-Windows-x64.zip`을 내려받고 압축을 풉니다.
2. 압축을 푼 폴더에서 PowerShell을 열고 `powershell -NoProfile -ExecutionPolicy Bypass -File .\Install-Widget.ps1`을 실행합니다.
3. `Win+D`로 바탕화면의 위젯을 확인합니다. 세션에는 Microsoft Edge WebView2 Runtime이 필요합니다.

현재 버전은 Windows WPF 데스크톱 프로그램입니다. 참고한 [아이젠하워 매트릭스 앱](https://apps.apple.com/kr/app/id6473735916)의 네 분면, 드래그 이동, 색상 분류, 반복, 알림 기능을 바탕화면 환경에 맞게 적용했습니다. 기본 테마는 다크이며 PC에 설치된 Apple SD Gothic Neo Medium/Bold를 사용합니다. 없는 PC에서는 Segoe UI로 대체합니다. Apple 폰트 파일은 프로그램에 재배포하지 않습니다.

## 위젯 안에서 바로 편집

- 각 분면의 **＋**를 누르면 위젯 내부 편집 화면이 열립니다. 별도의 할 일 추가 네비게이션 버튼은 없습니다.
- 할 일 제목을 누르면 같은 위젯 안에서 제목, 분류, 날짜, 카드 색상, 반복, 알림, 메모를 수정합니다.
- 매트릭스와 캘린더의 할 일 카드 왼쪽 체크박스로 바로 완료합니다. **보기 ≡ → 완료된 할 일만 보기**에서 체크를 풀면 할 일을 다시 미완료로 돌릴 수 있습니다.
- 편집 화면의 **삭제**를 두 번 누르면 삭제됩니다. 첫 클릭은 확인 안내입니다.
- **카테고리** 버튼은 같은 위젯 안에서 카테고리와 세부 분류를 만들고 이름을 변경하는 화면을 엽니다. 별도 관리 창은 없습니다.
- 할 일의 세부 카테고리는 상위 카테고리에 연결되며, 위젯 위쪽 **세부 분류**에서 필터링할 수 있습니다. 편집 화면에서 기존 분류를 선택하거나 새 이름을 입력합니다.
- **닫기/취소**는 한 번 누르면 바로 닫힙니다. 저장하려면 먼저 **저장**을 누르세요. 마감일은 `YYYY-MM-DD` 전체 형식과 실제 날짜를 검증하며, 달력에서 날짜만 선택해서 할 일이 자동 등록되지는 않습니다.
- 지정한 색상은 카드 배경, 굵은 왼쪽 강조선, 체크박스에 함께 반영됩니다. 제목과 분면 이름은 볼드입니다.

## Claude · Codex 사용 한도

**세션** 버튼은 같은 위젯 안에 사용률 카드를 표시합니다. **연결**을 누르면 로그인 화면도 같은 위젯 안에서 열립니다. 프로필은 `%USERPROFILE%\DesktopTodoVault\.profiles\claude`와 `.profiles\chatgpt`에 유지합니다. 위젯이 시작되면 저장된 두 로그인 세션을 동시에 확인합니다. 설치본 경로도 고정하고 비공개 브라우징은 사용하지 않습니다. 서비스가 인증을 만료·폐기하거나 보안 확인을 요구하면 다시 로그인해야 하며, 이를 영구히 우회하지는 않습니다.

Claude는 로그인된 브라우저의 동일 출처 요청으로 계정 사용률을 조회합니다. 서버 응답에 있는 현재 세션·주간 전체·Sonnet·Opus·추가 사용량 등을 카드로 표시하며, 잔여율은 `100 - 사용률`로 계산합니다. 초기화 시간을 남은 시간으로 표시하고 1분마다 갱신합니다. 사용량을 확인하면 로그인 화면에서 카드로 자동 복귀합니다. 이 조회는 공개 API가 아닌 서비스 내부 응답을 사용하므로 서비스 변경이나 접근 제한 시 실패할 수 있습니다. 실패 상태와 마지막 확인 시각을 표시하고 값을 임의로 생성하지 않습니다.

OpenAI 카드는 **Codex 사용 한도**를 표시합니다. Codex를 사용하는 ChatGPT 계정으로 한 번 로그인하면 저장된 브라우저 프로필을 재사용합니다. 공식 Codex 사용량 화면과 같은 출처에서 계정의 사용 한도를 조회하며, **5시간 한도**와 **주간 한도**를 항상 별개 카드로 표시합니다. 각 카드에는 해당 주기의 사용률·잔여율·초기화 시간만 연결합니다. 주간 한도만 조회되면 5시간 카드는 —로 남기고, 일일 한도를 대신 표시하지 않습니다. 데이터가 없거나 인증이 만료되면 0%를 만들어 표시하지 않습니다. 로그인 토큰은 브라우저 안에서 같은 서비스 요청에만 사용하며 파일이나 로그로 따로 저장하지 않습니다.

Codex 한도는 일반 ChatGPT 대화의 남은 메시지 수나 API 조직 토큰 사용량과 다릅니다. [Codex 공식 안내](https://developers.openai.com/codex/pricing/)를 참고하세요. 서비스 내부 응답 형식이 바뀌면 조회 방식 수정이 필요할 수 있습니다.

실행 폴더에는 `NativeTheme.xaml`, `Microsoft.Web.WebView2.Core.dll`, `Microsoft.Web.WebView2.Wpf.dll`, `WebView2Loader.dll`이 필요합니다. 세션창에는 Windows의 Edge WebView2 Runtime이 필요하며 기본 위젯 UI는 네이티브 WPF입니다.

- 할 일을 다른 분면으로 드래그하면 중요도·긴급도가 바뀝니다.
- 위젯 위쪽에서 카테고리와 색상을 필터링할 수 있습니다.
- 상단 네비게이션은 **매트릭스 / 캘린더 / 기록 / 세션**입니다. **보기 ≡** 메뉴에서 간결하게 보기, 완료된 할 일만 보기, 색상 필터를 설정합니다. 세션에서도 보기 메뉴는 유지하며 적용되지 않는 옵션은 비활성화합니다. 활성 버튼은 파란색입니다.
- 상세 편집에서 색상, 매일/매주/매월 반복, 알림 날짜·시간을 설정합니다. 반복 할 일을 완료하면 다음 일정을 한 번 생성합니다. Windows 알림은 프로그램 실행 중에 동작하며 운영체제의 알림 설정을 따릅니다.

`DesktopTodo.exe`를 실행하면 Windows 바탕화면에 위젯 하나가 표시됩니다. .NET Framework 4.8을 사용하며 별도 패키지 설치는 필요하지 않습니다.

- 기본 화면은 아이젠하워 매트릭스입니다. 지금 하기(중요·긴급), 계획하기(중요·비긴급), 위임하기(비중요·긴급), 줄이기(비중요·비긴급)에 미완료 할 일을 표시합니다.
- 상단 **캘린더** 버튼으로 같은 위젯을 월별 캘린더로 전환합니다. 날짜별 할 일을 확인하고 추가할 수 있습니다.
- 네 변의 테두리 또는 상단 빈 공간을 드래그하면 이동합니다. 네 모서리를 드래그하면 크기를 조절합니다. **크기 ▾** 메뉴에서 크기를 바로 선택할 수도 있습니다.
- **배치 잠금**은 위치·크기를 고정합니다. **잠금 해제**로 다시 조절합니다.
- 위치·크기·잠금은 조작 직후 자동 저장하고 다음 실행 시 복원합니다. 시작 화면은 매트릭스입니다.
- 설치본은 `%LOCALAPPDATA%\Programs\DesktopTodo`에서 실행합니다. OneDrive 동기화 상태에 의존하지 않습니다. `DesktopTodo` 예약 작업이 현재 사용자 로그인 15초 후 실행하고 실패 시 1분 간격으로 3회 재시도합니다. 배터리 상태로 중지되지 않으며 실행 시간 제한도 없습니다. 알림 영역 메뉴에서 자동 실행을 켜거나 끌 수 있습니다.
- 위젯은 Windows 바탕화면 계층에 붙어 일반 앱 아래에 표시됩니다. `Win+D`로 확인할 수 있습니다.
- 상단 `···` 또는 알림 영역 메뉴에서 위치·크기 초기화, 재연결, 자동 실행, 종료를 선택합니다. 초기화는 잠금을 풀고 왼쪽 위 650×540 크기로 되돌립니다.

## 수정 화면

할 일을 누르면 위젯 안에서 상세 편집이 열립니다. **카테고리**를 누르면 같은 위젯 안에서 분류를 관리합니다.

1. 카테고리 화면에서 상위 카테고리와 세부 카테고리를 추가·변경합니다. 사용 중인 분류를 삭제하려면 해당 할 일을 먼저 옮기세요. 이름 변경은 해당 할 일에 함께 반영됩니다.
2. **할 일 추가**를 누르고 제목, 카테고리, 세부 카테고리, 마감일, 우선순위, 메모를 작성합니다.
3. **중요한 일**, **긴급한 일**을 각각 체크하여 매트릭스 분면을 정합니다. 마감일과는 별도로 유지됩니다.
4. **저장**하면 위젯과 캘린더에 바로 반영됩니다. 완료한 일은 **보기 ≡ → 완료된 할 일만 보기**에서 볼 수 있습니다.

캘린더의 **오늘로 이동**은 현재 달로 돌아오고 오늘 날짜와 오늘의 일정을 선택합니다. 이미 오늘을 선택했다면 **오늘 선택됨**으로 비활성 표시됩니다. 좁은 창에서는 일정 목록이 달력 아래에, 넓은 창에서는 오른쪽에 표시됩니다. 세션 카드는 중앙에 배치되며 가용 너비에 따라 각 서비스의 카드가 여러 열로 펼쳐집니다.

기존 데이터는 보존합니다. 최초 업그레이드 때 높은 우선순위를 중요, 오늘·내일 또는 이미 지난 마감을 긴급으로 옮깁니다. 이후에는 직접 지정합니다.

## 데이터

`%USERPROFILE%\DesktopTodoVault`가 실제 로컬 저장소입니다. OneDrive나 클라우드 동기화를 사용하지 않습니다. `Tasks`에는 할 일마다 Markdown 파일 하나가 있고, 앞부분의 메타데이터에 제목·카테고리·날짜·완료·중요도·색상 등이, 본문에 메모가 들어갑니다. Obsidian에서 이 폴더를 열 수도 있습니다. `settings.json`은 배치와 카테고리 설정이며 할 일 본문을 저장하지 않습니다.

`History`에는 수정 전 파일과 삭제한 파일이 보존됩니다. 원래 `data.json`은 덮어쓰지 않고, 복구 원본은 `Recovery`에 보관했습니다. 외부에서 Markdown을 수정한 경우 앱의 배치 저장이 그 내용을 덮어쓰지 않습니다. 같은 항목을 앱과 외부에서 동시에 수정하면 충돌을 알리고 파일을 보존합니다. `.profiles`는 로그인 전용이므로 일반 할 일 Markdown과 분리됩니다.

프로그램 업데이트는 저장·정상 종료를 기다린 뒤 실행 파일만 교체합니다. 데이터와 프로필은 지우거나 초기화하지 않습니다. 설치본 외 경로에서 실행해도 고정 설치본으로 전달하며 로컬 파일 잠금으로 중복 실행을 막습니다.

## 빌드 및 검사

PowerShell에서 `powershell -ExecutionPolicy Bypass -File .\build.ps1` 실행. Windows 기본 C# 컴파일러로 네이티브 소스와 세션창을 빌드합니다. WebView2 SDK 파일이 없으면 빌드 스크립트가 지정된 버전을 NuGet에서 받아옵니다.

빌드 후 `powershell -ExecutionPolicy Bypass -File .\Install-Widget.ps1`을 실행하면 로컬 설치본을 갱신하고 로그인 예약 작업을 등록합니다. 저장 데이터와 로그인 프로필은 `DesktopTodoVault`에 유지합니다. 기존 Run 레지스트리 등록은 중복 실행을 막기 위해 제거합니다. `--startup-test`는 처음 두 번의 바탕화면 연결을 지연시켜 준비 후 자동 연결되는지 검사합니다. 모든 테스트는 임시 저장소와 임시 로그인 프로필만 사용합니다.

위젯의 조작 버튼은 같은 너비·32 높이를 사용합니다. 창이 좁아지면 모든 버튼 너비를 함께 줄입니다. 할 일 카드 전체를 누르는 영역과 캘린더 날짜 셀은 반응형 레이아웃에 맞춰 늘어납니다.

- `DesktopTodo.exe --self-test`: 데이터 이관, 네 분면 분류, 위치·크기·잠금 저장, 백업 검사. 결과는 `test-results.txt`입니다.
- `DesktopTodo.exe --ui-test`: 프로그램 종료 후 실행합니다. 임시 데이터로 실제 컨트롤의 크기 조절·잠금·화면 전환·편집·카테고리 이름 변경·검색·저장 파일에서 창 복원을 검사합니다. 사용자 데이터와 자동 실행 설정을 바꾸지 않습니다. 결과는 `ui-test-results.txt`입니다.
- `DesktopTodo.exe --smoke-test`: 임시 저장소로 화면을 렌더링한 뒤 종료합니다.
- `DesktopTodo.exe --vault-test`: Markdown 이전, 외부 편집 보호, 삭제 이력, 실사용 프로필과 테스트 분리를 검사합니다.
- `DesktopTodo.exe --session-test`: 두 서비스의 내장 브라우저와 분리된 프로필 초기화를 검사합니다. 계정 로그인·구독 잔여량 검사는 사용자 로그인이 필요합니다. 결과는 `session-test-results.txt`입니다.

Explorer의 SHELLDLL_DefView에 붙이고 소프트웨어 렌더링을 사용하여 Wallpaper Engine과 함께 표시합니다. Explorer 재시작이나 로그인 시 바탕화면 준비가 늦어지면 재연결을 시도합니다. Windows 업데이트, 대체 셸, 모니터 구성 변경에 따른 호환성 차이는 있을 수 있습니다.
