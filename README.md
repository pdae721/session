# Session · 바탕화면 매트릭스

Windows 10/11 x64 바탕화면에서 할 일과 Claude·Codex 사용 한도를 확인하는 위젯입니다.

## 설치

1. [GitHub Releases](https://github.com/pdae721/session/releases/latest)에서 `Session-Windows-x64.zip`을 내려받고 압축을 풉니다.
2. 압축을 푼 폴더에서 PowerShell을 열고 `powershell -NoProfile -ExecutionPolicy Bypass -File .\Install-Widget.ps1`을 실행합니다.
3. `Win+D`로 바탕화면의 위젯을 확인합니다. 세션에는 Microsoft Edge WebView2 Runtime이 필요합니다.

## Claude · Codex 사용 한도

**세션** 버튼은 같은 위젯 안에 사용률 카드를 표시합니다. **연결**을 누르면 로그인 화면도 같은 위젯 안에서 열립니다. 프로필은 `%USERPROFILE%\DesktopTodoVault\.profiles\claude`와 `.profiles\chatgpt`에 유지합니다. 위젯이 시작되면 저장된 두 로그인 세션을 동시에 확인합니다. 설치본 경로도 고정하고 비공개 브라우징은 사용하지 않습니다. 서비스가 인증을 만료·폐기하거나 보안 확인을 요구하면 다시 로그인해야 하며, 이를 영구히 우회하지는 않습니다.

Claude는 로그인된 브라우저의 동일 출처 요청으로 계정 사용률을 조회합니다. 서버 응답에 있는 현재 세션·주간 전체·Sonnet·Opus·추가 사용량 등을 카드로 표시하며, 잔여율은 `100 - 사용률`로 계산합니다. 초기화 시간을 남은 시간으로 표시하고 1분마다 갱신합니다. 사용량을 확인하면 로그인 화면에서 카드로 자동 복귀합니다. 이 조회는 공개 API가 아닌 서비스 내부 응답을 사용하므로 서비스 변경이나 접근 제한 시 실패할 수 있습니다. 실패 상태와 마지막 확인 시각을 표시하고 값을 임의로 생성하지 않습니다.

OpenAI 카드는 **Codex 사용 한도**를 표시합니다. Codex를 사용하는 ChatGPT 계정으로 한 번 로그인하면 저장된 브라우저 프로필을 재사용합니다. 공식 Codex 사용량 화면과 같은 출처에서 계정의 사용 한도를 조회하며, **5시간 한도**와 **주간 한도**를 항상 별개 카드로 표시합니다. 각 카드에는 해당 주기의 사용률·잔여율·초기화 시간만 연결합니다. 주간 한도만 조회되면 5시간 카드는 —로 남기고, 일일 한도를 대신 표시하지 않습니다. 데이터가 없거나 인증이 만료되면 0%를 만들어 표시하지 않습니다. 로그인 토큰은 브라우저 안에서 같은 서비스 요청에만 사용하며 파일이나 로그로 따로 저장하지 않습니다.

Codex 한도는 일반 ChatGPT 대화의 남은 메시지 수나 API 조직 토큰 사용량과 다릅니다. [Codex 공식 안내](https://developers.openai.com/codex/pricing/)를 참고하세요. 서비스 내부 응답 형식이 바뀌면 조회 방식 수정이 필요할 수 있습니다.

Explorer의 SHELLDLL_DefView에 붙이고 소프트웨어 렌더링을 사용하여 Wallpaper Engine과 함께 표시합니다. Explorer 재시작이나 로그인 시 바탕화면 준비가 늦어지면 재연결을 시도합니다. Windows 업데이트, 대체 셸, 모니터 구성 변경에 따른 호환성 차이는 있을 수 있습니다.
